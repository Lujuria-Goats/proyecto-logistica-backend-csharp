### Migración 2: AddSavedRoutesTable (20251204141905)
**Tabla Creada**:
- SavedRoutes

**Estructura**:
```sql
CREATE TABLE "SavedRoutes" (
    "Id" int GENERATED BY DEFAULT AS IDENTITY,
    "DriverId" int NOT NULL,
    "RouteName" varchar(100) NOT NULL,
    "OrderIds" text NOT NULL,
    "CreatedDate" timestamp with time zone NOT NULL,
    "LastUsedDate" timestamp with time zone NULL,
    "IsActive" bool NOT NULL DEFAULT true,
    "OptimizationScore" int NULL,
    CONSTRAINT "PK_SavedRoutes" PRIMARY KEY ("Id"),
    CONSTRAINT "FK_SavedRoutes_AspNetUsers_DriverId" 
        FOREIGN KEY ("DriverId") REFERENCES "AspNetUsers"("Id") ON DELETE CASCADE
);

CREATE INDEX "IX_SavedRoutes_DriverId" ON "SavedRoutes"("DriverId");
```

**Relación**: SavedRoute (many) → User/Driver (one)
- Cascada: Si se elimina un Driver, se eliminan sus rutas guardadas
